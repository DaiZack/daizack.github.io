Featured Project

FolderLake — a personal data lake over your own foldersOpen Source · MIT

FolderLake catalogs files in place with DuckDB — no copying, no uploading. For each file it extracts topic tags, a one-line summary and key entities (TF-IDF / NLP pipeline + LLM tier), then links files into a graph by topic similarity, shared entities and references, so you can find anything by type and topic in seconds. Ships with a local web app, an MCP interface, PyPI package and desktop apps.
